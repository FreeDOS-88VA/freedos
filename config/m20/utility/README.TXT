PC-88VA FreeDOS M20 - utilities disk (drive B:)

This is a data disk for drive B:. It is not bootable: boot from the M20
system disk in drive A:, insert this disk in drive B: and run the programs
from B: (for example B:FIND /?), or copy them to a working disk.

Programs
--------
FIND.EXE   Search for text in files (FreeDOS FIND 3.0b).

Every program is built from its pinned public source with Open Watcom 1.9
for 8086 real mode; messages are English. The corresponding source of every
program is in the separate host-side M20 source bundle.
