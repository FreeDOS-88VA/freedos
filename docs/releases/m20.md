# M20 release candidate 4 — FreeDOS 1.4 based PC-88VA disk set

## Validation boundary: emulator only, release candidate

**This is a release candidate (prerelease) validated on emulators only (エミュレータ検証のみ).**

- **HOST PASS**: public-input-only clean builds, two-build byte comparison, M20 host tests, byte-identity of the non-PC-88VA kernel and forked utility builds with FreeDOS 1.4 (FreeCOM: with FreeDOS 1.4 plus the recorded kswap fix series), and native x64 CI.
- **VAEG PASS**: bounded VA/VA2 boot, shell menu, FreeCOM and MS-DOS 4 COMMAND, DEBUG and startup-key checks (utilities/archivers from earlier candidates) listed in the [report](../porting/m20-report.md) and [manifest](../../images/milestones/m20/manifest.json).
- **DEFERRED HARDWARE VALIDATION**: hardware is **NOT RUN**; no HARDWARE PASS is claimed.

M20 restarts the port on the FreeDOS 1.4 release sources (kernel `ke2043`, FreeCOM `com086`) with selectively imported changes. English only; Japanese support is planned for the next milestone.

## Downloads

Three native 80-cylinder, 2-head, 8-sector/track, 1024-byte/sector FAT12 2HD disks. Use **writable copies** in a supported VA/VA2 emulator with operator-supplied licensed ROMs; no ROM or private disk is included.

- System (A:, bootable): FreeDOS kernel with a startup shell menu — **1** FreeCOM 0.86 through KSSF (swaps itself out while a program runs) or **2** MS-DOS 4.0 COMMAND.COM (`A:\MSDOS`) — plus EDLIN, MORE, MEM, JWASMR, DEBUG, native-2HD FORMAT/CHKDSK/SYS and COM/MZ examples.
- Utilities (B:, label `M20-UTIL`): FIND, SORT, XCOPY, LABEL, MOVE, APPEND, NLSFUNC, DEVLOAD, CHOICE, DELTREE, COMP, FC, ATTRIB, TREE, REPLACE, EXE2BIN.
- Archivers and tools (B:, label `M20-ARC`): UNZIP, ZIP, GZIP (16-bit builds) and DEBUG. They need **640 KiB** installed.

## Changes since release candidate 3

- **FreeDOS MEM** replaces MEMMAP (`MEM`, `MEM /C`, `MEM /D`). It is FreeDOS MEM 1.11 built for the VA: conventional memory comes from DOS, not from PC BIOS calls. MEM counts the VA firmware area below 64 KiB as SYSTEM.
- **Less memory used**: the kernel no longer keeps its one-time machine initialization and milestone diagnostics resident (about 2.7 KB), and `STACKS=0,0` drops the 2 KB interrupt-stack pool. Free memory on 640 KiB (MEM /C at the prompt): **507,760 bytes** with FreeCOM (swapped), **506,352 bytes** with MS-DOS 4 COMMAND (release candidate 3: 505,008 with FreeCOM).

## Changes in release candidate 3

- **Shell menu at startup**: 1 = FreeCOM (default; Enter or 5 seconds), 2 = MS-DOS 4.0 COMMAND.COM built from Microsoft's MIT-licensed source (`A:\MSDOS`, license `MSDOS.LIC`). F5 and F8 work in the menu.
- **FreeCOM swaps by default** (`/SWAP`); batch files, redirection and pipes run without swapping. FreeCOM's long-filename support is removed. AUTOEXEC.BAT sets `PATH A:\`.
- The owner reports a boot, command execution and file write on a real PC-88VA2 with 640 KB using release candidate 1 (owner report, not a HARDWARE PASS).

## Known issues and limits

- FreeCOM does not swap in batch files, redirection, pipes or secondary shells. MS-DOS 4 COMMAND has no HELP, history or aliases and was not tested at 384/512 KiB.

- Hardware untested. Memory: 640 KiB is the qualified setting for JWASMR and the archivers; at 384 KiB JWASMR cannot start, at 256 KiB SORT, XCOPY and MOVE fail for lack of memory.
- Not ported: UNDELETE, SWSUBST, SHARE; FAT32 is off.
- The stable M18 and M19 Preview 1 kernels contain a startup-key defect (F5/F8 window wrong on VA2, absent on VA) that M20 fixes.
- Upstream FreeDOS 1.4 behavior is kept as is (not repaired), for example the UNZIP time-zone warning and GZIP 8.3 naming.
- Regression beyond scratch PC boot smoke tests was not run.

## Rebuild from public source

```sh
git clone https://github.com/FreeDOS-88VA/freedos.git && cd freedos
git checkout 7a62a6595b78f36c407e6b9ee999f30c450f7618
git submodule update --init --recursive
make m20-toolchain
make m20-disk
make m20-accept
sha256sum dist/m20/*.D88 dist/m20/*SOURCES.tar.xz
```

The hashes must match the table above. Extraction check: `xz -dc images/milestones/m20/<file>.d88.xz | sha256sum`.
